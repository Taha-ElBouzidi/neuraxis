# How to track follow-ups on sent email

The point is to catch what would otherwise slip quietly: an email sent, no reply, and nobody notices that it went cold. Use the person's mail tools (whatever is connected: an MCP server, a mail client, a browser). For commitments made in meetings, see [[reference_how_to_handle_meetings_and_follow_ups]]; this method covers sent mail.

List the sent mail of the last 14 days and note recipient, subject, date sent and thread for each. For every one, check the same thread, or search for mail from that recipient on that subject, for a reply.

## Age groups

- **Replied:** a response arrived; nothing to do.
- **Recent:** sent less than 3 days ago; too early to expect anything.
- **No reply, 3 to 7 days:** worth watching.
- **No reply, 7 days or more:** overdue; a real follow-up candidate.

Skip automated and no-reply addresses, and skip mailing lists and group addresses: only individual recipients are tracked. If the volume is too large to process fully, work the last 7 days first.

## The report

List the overdue ones first, each with recipient, subject and days since sent, and offer to draft a follow-up for each. List the 3-to-7-day ones the same way, without the offer yet. Give a one-line count for the recent ones and a one-line count of those that already got a reply.

## Drafting the nudge

Read the original sent email first. The nudge refers to it briefly, restates the ask in short form, and gives an easy way out, for example "if this is no longer relevant, no worries". It is never pushy and never passive-aggressive. Follow [[reference_how_to_write_an_email]], present the draft, and save it as a draft in the mail tool only once the person approves.

## What not to do

- Never send a follow-up without explicit approval of the draft.
- Never invent the original ask; take it from the actual sent email.
- Do not chase an address that never replies by design.
